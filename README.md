## プログラムについて
指定したファイルが現在のリポジトリにおいて、以下のどの状態にあるかを自動で判定してくれるコマンド。
- まだコミットされていない。
- コミット済みだがまだGitHubにプッシュされていない。
- すでにGitHubにプッシュ済みである。
